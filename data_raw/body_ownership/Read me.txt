The file named "analysis script" contains the analysis R code. Analyses are run on two databases:
- "db total" is the main database;
- "dt2.noout" is the long format database for the proprioceptive drift analysis; here, we have each pointing trial instead of the averaged score.

Databases' codebooks follow.
